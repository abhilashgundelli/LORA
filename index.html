Algorithm Pseudocode

Time: O(1) per day 
Algorithm LearningAugmentedSkiRental(B, D_hat, λ):
  // Input: Buy cost B, ML prediction D_hat, trust λ ∈ (0, 1]
  if D_hat >= B then
      t_buy ← ceil(λ * B)       // Trust long trip: buy early
  else
      t_buy ← ceil(B / λ)       // Trust short trip: wait longer
  end if

  for day t = 1, 2, ... while still skiing do
      if t == t_buy then
          BuySkis()             // Pay B, cost = (t_buy - 1) + B
          break
      else
          RentSkis()            // Pay 1 for day t
      end if
  end for

Key Viva Takeaways

  • Why Classical Fails to Use Predictions: Deterministic online algorithms assume an omniscient adversary, forcing a $2 - 1/B$ lower bound.
  • Role of $\lambda$: Interpolates smoothly between blind trust ($\lambda \to 0$) and classical worst-case safety ($\lambda = 1$).
  • Randomized Extension: Sampling $t_{\text{buy}}$ from an exponential distribution improves the frontier to $\left(\frac{\lambda}{1-e^{-\lambda}}, \frac{1}{1-e^{-\lambda}}\right)$, beating $e/(e-1) \approx 1.58$.

Formal Competitive Analysis Proofs

Theorem 1: $(1 + \lambda)$-Consistency (When $\hat{D} = D$)

Let $k = B/r$ denote the normalized purchase cost in rental days. Assume the ML predictor is exact ($\hat{D} = D$). We analyze two exhaustive cases:

Case 1 ($D \ge k$): Offline optimal buys on Day 1, so $\text{OPT} = B = kr$. Since $\hat{D} = D \ge k$, our algorithm sets $t_{\text{buy}} = \lceil \lambda k \rceil \le \lambda k + 1$. Since $D \ge k \ge \lceil \lambda k \rceil$, the algorithm buys on day $t_{\text{buy}}$: $$\text{ALG} = (\lceil \lambda k \rceil - 1)r + B \le \lambda kr + B = (1 + \lambda)B = (1 + \lambda)\text{OPT}$$

Case 2 ($D < k$): Offline optimal rents every day, so $\text{OPT} = Dr$. Since $\hat{D} = D < k$, the algorithm sets $t_{\text{buy}} = \lceil k/\lambda \rceil \ge k > D$. The trip ends before day $t_{\text{buy}}$, so it rents all $D$ days: $$\text{ALG} = Dr = 1 \cdot \text{OPT} \le (1 + \lambda)\text{OPT}$$

Theorem 2: $(1 + 1/\lambda)$-Robustness (Arbitrary Prediction Error)

Suppose $\hat{D}$ is adversarially inaccurate. With $k = B/r$, we bound $\text{ALG}/\text{OPT}$ across both prediction regimes:

Case 1 ($\hat{D} \ge k$, so $t_{\text{buy}} = \lceil \lambda k \rceil$): Maximum cost occurs if $D \ge t_{\text{buy}}$, yielding $\text{ALG} \le \lambda kr + B = (1 + \lambda)B$. Meanwhile, $\text{OPT} = \min(Dr, B) \ge \min(\lceil \lambda k \rceil r, B) \ge \lambda B$. Thus: $$\frac{\text{ALG}}{\text{OPT}} \le \frac{(1 + \lambda)B}{\lambda B} = 1 + \frac{1}{\lambda}$$

Case 2 ($\hat{D} < k$, so $t_{\text{buy}} = \lceil k/\lambda \rceil$): If $D \ge t_{\text{buy}}$, $\text{OPT} = B$ and: $$\text{ALG} = (\lceil k/\lambda \rceil - 1)r + B < \frac{k}{\lambda}r + B = \left(1 + \frac{1}{\lambda}\right)\text{OPT}$$
